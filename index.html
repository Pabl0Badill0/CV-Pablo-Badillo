Sitio Web Profesional para Psicólogo

Diseño y desarrollo de un sitio web profesional enfocado en presentar el perfil, áreas de especialidad y servicios de un psicólogo. La plataforma funciona como una tarjeta de presentación digital interactiva que permite a los pacientes conocer su información detallada y establecer contacto directo mediante un formulario integrado al correo electrónico.

Herramientas y Tecnologías:
HTML5 / CSS3 JavaScript Formulario de Contacto Diseño Responsivo
PROYECTO DE TESIS / API BACKEND

SGILA - Sistema para Laboratorios

Plataforma integral que optimiza la administración de múltiples sedes mediante una API en tiempo real. El sistema sincroniza el control de inventario dinámico con la supervisión de personal, automatizando la verificación de asistencias y el cumplimiento de guardias. Además, garantiza la trazabilidad total de los activos mediante un historial detallado de préstamos y un motor de notificaciones que gestiona alertas entre laboratorios y recordatorios automáticos por correo.

Herramientas y Tecnologías:
Python PostgreSQL Lógica API React & Tailwind Tkinter
DISEÑO Y DESARROLLO WEB

Sitio Web para Constructora

Creación de un sitio web profesional e intuitivo para una empresa del sector de la construcción o remoelacion. Su objetivo es visualizar de manera atractiva el portafolio de obras finalizadas, detallar los servicios ofrecidos y proporcionar una vía de contacto directo con clientes potenciales.

Herramientas y Tecnologías:
HTML5 CSS3 TypeScript JavaScript Node-which
